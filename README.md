## DS Harness Desktop v1.0.0

首个 Windows 桌面版本。

### 功能

- 基于 DeepSeek Harness
- 支持 OpenAI 兼容 API
- 支持自由配置和切换模型
- 支持 K3、DeepSeek V4 Pro 等模型
- 自动创建本地工作区
- API Key 仅保存在当前电脑

### 安装

下载下方的 `DS-Harness-Desktop-Setup-1.0.0.exe` 并运行安装。

首次启动时，请填写自己的 API Base URL、API Key 和可用模型。
